Local API DeepSeek

DeepSeek V4.1 Flash 1017. Ключ и история остаются на устройстве, запросы идут напрямую в DeepSeek.

Уведомления
О готовом ответе, когда приложение свёрнуто
Оптимизация батареи
Чтобы система не останавливала длинные ответы

Разрешения можно изменить в настройках Android.

Samsung/One UI: приложение → «Использование батареи» → «Разрешить энергопотребление в фоновом режиме»; отключите «Приостанавливать работу приложения…». Xiaomi/HyperOS: автозапуск и «Без ограничений».

Подключение

Вставьте API-ключ. Приложение проверит его запросом к /models и сохранит на устройстве.

platform.deepseek.com → API keys → Create new key
