# Как получить userToken для веб-режима

`userToken` — токен вашей сессии на `chat.deepseek.com`. Он даёт полный доступ к аккаунту, поэтому храните его как пароль.

- Формат: строка длиной ~64 символа без префикса `sk-`.
- В браузере хранится как JSON `{"value":"<token>","__version":"0"}`. Приложение примет и весь JSON целиком, и одно значение `value`.
- Токен не привязан к устройству: можно вытащить его на ПК и перенести на телефон.

Не путайте с API-ключом (`sk-…`) с `platform.deepseek.com` — он вводится на вкладке «API-ключ».

---

## Windows / macOS / Linux

### Chrome, Edge, Brave, Opera, Vivaldi

1. Откройте <https://chat.deepseek.com> и войдите в аккаунт.
2. Нажмите `F12` (Windows/Linux) или `Cmd+Option+I` (macOS).
3. Перейдите в **Application → Storage → Local Storage → `https://chat.deepseek.com`**.
4. Найдите ключ `userToken` (`{"value":"HRN0…","__version":"0"}`) и скопируйте значение.

Быстрее через вкладку **Console**:

```js
copy(JSON.parse(localStorage.getItem("userToken")).value)
```

### Firefox

1. Войдите на сайте и нажмите `F12`.
2. **Storage → Local Storage → `https://chat.deepseek.com` → `userToken`**, либо выполните в **Console**:

```js
copy(JSON.parse(localStorage.getItem("userToken")).value)
```

Если `copy()` заблокирован, выполните без обёртки `copy(...)` и скопируйте строку из вывода вручную.

### Safari (macOS)

1. Включите **Safari → Настройки → Дополнения → Показывать функции для веб-разработчиков**.
2. Войдите на сайте и откройте **Разработка → Показать веб-инспектор**.
3. **Хранилище → Локальное хранилище → `chat.deepseek.com` → `userToken`**, либо в **Консоли**:

```js
JSON.parse(localStorage.getItem("userToken")).value
```

## Android

### Вариант 1. Через ПК (проще всего)

Войдите в аккаунт на компьютере, скопируйте `userToken` по инструкции выше и перешлите на телефон. Мобильный браузер для этого не понадобится.

### Вариант 2. Chrome на телефоне + отладка по USB

1. Включите режим разработчика на телефоне (**Настройки → О телефоне → Номер сборки** — 7 нажатий) и активируйте **Отладку по USB**.
2. Подключите телефон к ПК, откройте `chat.deepseek.com` в мобильном Chrome и войдите.
3. На компьютере перейдите в `chrome://inspect/#devices`, найдите вкладку `chat.deepseek.com` и нажмите **inspect**.
4. В открывшейся **Console** выполните:

```js
JSON.parse(localStorage.getItem("userToken")).value
```

Если вкладка не появляется в списке, разблокируйте экран, оставьте сайт активным и нажмите **Reload** в `chrome://inspect`.

### Вариант 3. Firefox для Android + букмарклет

1. Установите Firefox и войдите на `chat.deepseek.com`.
2. Добавьте любую закладку и замените её адрес на строку:

```text
javascript:(()=>{try{prompt('userToken',JSON.parse(localStorage.getItem('userToken')).value)}catch(e){prompt('Ошибка',String(e))}})()
```

3. Находясь на вкладке `chat.deepseek.com`, откройте закладки и нажмите на созданную — появится окно с токеном.

## iPhone / iPad

- **Через ПК**: получите токен на компьютере и вставьте в приложении.
- **Через Safari + Mac**: включите на iPhone **Настройки → Safari → Дополнения → Веб-инспектор**, подключите к Mac, откройте сайт на iPhone и на Mac перейдите в **Разработка → [ваш iPhone] → `chat.deepseek.com`**, затем выполните в консоли:

```js
JSON.parse(localStorage.getItem("userToken")).value
```

- **Через букмарклет в Safari**: аналогично способу 3 для Firefox.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| Ключа `userToken` нет | Вы не авторизованы или открыт не `https://chat.deepseek.com`. |
| «Веб-токен недействителен или истёк» | Сессия завершена (выход, смена пароля, отзыв). Войдите заново и возьмите новый токен. |
| «DeepSeek вернул не JSON» | Сработала защита Cloudflare/WAF. Откройте сайт в браузере под этим аккаунтом и повторите позже. |
| Ошибка `40003` | Неверный ключ (например, вставлен `sk-…`) или сессия уже мертва. |
| Кнопка «Проверить и сохранить» неактивна | Поле пустое или токен короче 8 символов. Воспользуйтесь кнопкой «вставить» или введите значение целиком. |

## Безопасность

- `userToken` открывает полный доступ к аккаунту — не пересылайте его никуда и не публикуйте.
- При утечке завершите все сессии в настройках аккаунта DeepSeek и авторизуйтесь заново.
- Веб-режим неофициальный: DeepSeek может блокировать такие клиенты без предупреждения.
