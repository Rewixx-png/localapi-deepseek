# Как получить userToken для веб-режима

`userToken` — это токен вашей сессии на `chat.deepseek.com`. Он даёт доступ к
аккаунту целиком, поэтому обращайтесь с ним как с паролем.

- Формат: строка ~64 символа без префикса `sk-`.
- В браузере лежит как JSON: `{"value":"<token>","__version":"0"}`.
- Приложение принимает и весь JSON, и одно значение `value`.
- Токен не привязан к устройству: можно один раз получить его на компьютере и
  вставить в приложение на телефоне. Это самый простой путь для Android.

Не путайте с API-ключом: он начинается с `sk-`, создаётся на
`platform.deepseek.com` и подходит только для вкладки «API-ключ».

---

## Windows / macOS / Linux

### Chrome, Edge, Brave, Opera, Vivaldi

1. Откройте <https://chat.deepseek.com> и войдите в аккаунт.
2. Нажмите `F12` (Windows/Linux) или `Cmd+Option+I` (macOS).
3. Вкладка **Application** → слева **Storage → Local Storage** →
   `https://chat.deepseek.com`.
4. В таблице найдите ключ `userToken`. Значение выглядит как
   `{"value":"HRN0…","__version":"0"}`.
5. Скопируйте значение и вставьте в приложение целиком — JSON тоже подойдёт.

Быстрый способ через консоль (вкладка **Console**):

```js
JSON.parse(localStorage.getItem("userToken")).value
```

Chrome сразу кладёт результат в буфер обмена, если обернуть в `copy()`:

```js
copy(JSON.parse(localStorage.getItem("userToken")).value)
```

### Firefox

1. Откройте сайт и войдите.
2. `F12` → вкладка **Storage** → **Local Storage** → `https://chat.deepseek.com`
   → `userToken`.
3. Либо **Console**:

```js
copy(JSON.parse(localStorage.getItem("userToken")).value)
```

Если `copy()` недоступен, выполните выражение без обёртки и скопируйте строку
из вывода вручную.

### Safari (macOS)

1. Safari → **Настройки** → **Дополнения** → включите
   «Показывать функции для веб-разработчиков».
2. Откройте сайт, войдите, затем **Разработка → Показать веб-инспектор**.
3. **Хранилище → Локальное хранилище → chat.deepseek.com → userToken**.
4. Либо **Консоль** (может потребоваться разрешить вставку):

```js
JSON.parse(localStorage.getItem("userToken")).value
```

## Android

### Способ 1. Получить токен на компьютере (рекомендую)

Токен не привязан к устройству. Войдите в тот же аккаунт на ПК, скопируйте
`userToken` по инструкции выше и вставьте в приложение на телефоне. Мобильный
браузер для этого не нужен.

### Способ 2. Chrome с телефона + отладка по USB

1. На телефоне: **Настройки → О телефоне → Номер сборки** — нажмите 7 раз,
   появится «Для разработчиков».
2. **Для разработчиков → Отладка по USB** — включите.
3. Подключите телефон к компьютеру по USB, подтвердите запрос отладки.
4. На телефоне откройте `chat.deepseek.com` и войдите.
5. На компьютере в Chrome откройте `chrome://inspect/#devices`.
6. Найдите вкладку `chat.deepseek.com` → **inspect**.
7. В открывшемся DevTools → **Console**:

```js
JSON.parse(localStorage.getItem("userToken")).value
```

8. Скопируйте строку и вставьте в приложение.

Если вкладки нет в списке: разблокируйте телефон, оставьте сайт активной
вкладкой Chrome и нажмите «Reload» в `chrome://inspect`.

### Способ 3. Firefox для Android + букмарклет

1. Установите Firefox, войдите на `chat.deepseek.com`.
2. Меню → **Закладки** → добавьте закладку с любым именем (например, `DS token`).
3. Отредактируйте её адрес на такую строку (целиком, одной строкой):

```text
javascript:(()=>{try{prompt('userToken',JSON.parse(localStorage.getItem('userToken')).value)}catch(e){prompt('Ошибка',String(e))}})()
```

4. Откройте `chat.deepseek.com`, откройте закладки и нажмите `DS token`.
5. Появится диалог с токеном — скопируйте его.

Букмарклет работает только на странице `chat.deepseek.com`: он читает
`localStorage` этого сайта.

### Чего на Android нет

В мобильном Chrome нет панели DevTools, поэтому «просто нажать F12» не
получится. Варианты выше — рабочие обходные пути; проще всего способ 1.

## iPhone / iPad

### Способ 1. Токен с компьютера

Так же, как для Android: получите токен на ПК и вставьте в приложение.

### Способ 2. Safari + Mac

1. На iPhone: **Настройки → Safari → Дополнения → Веб-инспектор** — включите.
2. Подключите iPhone к Mac по кабелю, доверьте устройство.
3. На iPhone откройте `chat.deepseek.com` и войдите.
4. На Mac: Safari → **Разработка → [имя iPhone] → chat.deepseek.com**.
5. **Консоль**:

```js
JSON.parse(localStorage.getItem("userToken")).value
```

### Способ 3. Букмарклет в Safari

Добавьте закладку, измените её адрес на строку из раздела Firefox, откройте
сайт и нажмите закладку. Safari на iOS поддерживает `javascript:`-закладки,
но может показать предупреждение.

## Если не получается

| Симптом | Причина / решение |
|---|---|
| Ключа `userToken` нет | Вы не вошли или открыт другой домен. Нужен именно `https://chat.deepseek.com`. |
| В значении только `{"value":"…"}` | Это нормально: приложение само достанет `value`. |
| «Веб-токен недействителен или истёк» | Сессия завершена (выход, смена пароля, отзыв). Войдите заново и скопируйте новый токен. |
| «DeepSeek вернул не JSON» | Сработала проверка Cloudflare/WAF. Помогает вход в браузере на этом же аккаунте и повтор позже. |
| Ошибка `40003` | Сервер не принял токен: скопирован не тот ключ (например, `sk-…`) или сессия мертва. |
| Кнопка «Проверить и сохранить» неактивна | Поле пустое или короче 8 символов. Вставьте токен ещё раз (в версии 1.2.0 кнопка «вставить» включает её автоматически). |

## Безопасность

- `userToken` = полный доступ к аккаунту. Не отправляйте его в чаты, тикеты и
  сторонние сервисы.
- Если токен засветился — выйдите из аккаунта на всех устройствах
  (это отзовёт сессию) и войдите заново.
- Приложение хранит токен в приватной папке (`0600`) и исключает его из
  резервных копий, но не шифрует отдельным ключом Android Keystore.
- Веб-режим неофициальный: DeepSeek может заблокировать такие клиенты.
